## Открытые пункты (живой бэклог)
1. **Мастер настройки может зависнуть на финальном шаге** (загрузка +
   самопроверка): сначала появляется ошибка, затем ничего не происходит —
   разобраться.
2. **Общие настройки распознавания**: сервисные блоки по выбору не включаются.

Помимо бэклога: план локального рантайма (этапы A–H) завершён, рабочее
состояние сохраняется вместе с документом (`.llocr`, ADR 131), а RAG остаётся
отложенным (ADR 6). Юнит-тесты провайдера/сетевого пути и установщики
остаются в рамках Этапа 5.
