  - средний - ocr-модель, decision модель проверяет layouts если ок - проверяет блоки, layout-модель размечает заново страницы, где найдено неосоответствие layout, block ocr модель проверяет проблемные блоки и распознаёт блоки на страницах с проблемным layout. Decision - модель проверяет блоки, расознанные block ocr моделью.
  - для сложных случаев - медленно (разметка, block ocr модель, decision модель)
