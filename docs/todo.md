- Поведение
  - Результат моделей OCR кладётся всегда в изначальную текстовую ячейку блока (box.text).
  - Результат универсальных моделей кладётся в ячейку корректировки (box.correctedText). Если модель возвращает OK, просто дублировать изначальный текст.
  - При повторном распознавании блока статус проверки, её результат и результат в box.correctedText удаляются.
  - При проверке или повторной проверке статус проверки и её результат стирается.
- Интерфейс
  - встплывающее меню блока

    - исправить - исправляет распознанный текст, обнуляет статус проверки (недоступно для нажатия, если нет распознанного текста)

- Статусы бокса: распознано - серый (есть результат распозанвания), проверено - красный или зелёный (есть результат проверки), исправлено - опять серый (есть результат исправления). При удалении результата исправления удалять и результат проверки исправления, если он есть, откатываться к статусу распознано или проверено (если была проверка).
