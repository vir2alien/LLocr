# Модели: Qwen3.5-4B / 9B (fix)

> Ручной запуск, контракт запросов и подключение в приложении для дефолта
> семейства исправления. English version: `docs/26-qwen3.5.md`. Сам
> протокол исправления: ADR 163, ADR 180 и
> `docs/todo/fix_models_improvements.md`; второе семейство fix (Gemma 4
> QAT): `docs/16-gemma-4.ru.md`.

## 1. Что это

**Qwen3.5-4B** и **Qwen3.5-9B** (упаковка unsloth -MTP) — универсальные
instruct-VLM в задаче **fix**: получают кроп блока плюс OCR-кандидат,
обрамлённый как данные, и отвечают по трёхтокенному контракту
**OK / FIX / REVIEW**. FIX несёт span-правки (строки вида
`old_substring => new_substring`) для текстовых блоков, полный
исправленный формуляр для блока-формулы и полный исправленный блок с
обязательной секцией `EDITS:` для таблицы; детерминированный дифф-гейт
применяет правки к самому кандидату (протокол `span_hybrid`, ADR 180 — он
заменил полный блок из ADR 163), а полный формуляр читается как
исправление (ADR 181). 4B — дефолтная
модель задачи (ADR 169); 9B — тот же рецепт большего размера. Лицензия
Apache-2.0.

## 3. Запуск

```
llama-server \
  --model <modelsDir>/unsloth__Qwen3.5-4B-MTP-GGUF/Qwen3.5-4B-Q8_0.gguf \
  --mmproj <modelsDir>/unsloth__Qwen3.5-4B-MTP-GGUF/mmproj-F16.gguf \
  --alias llocr-fix \
  --host 127.0.0.1 --port <авто> \
  --spec-type draft-mtp --spec-draft-n-max 4 --special --temp 0 \
  --parallel 1 --no-warmup --jinja --reasoning-budget 0 \
  --flash-attn on --image-min-tokens 1024 \
  --n-gpu-layers 99 \
  --cache-reuse 0 --no-context-shift
```

- **`--spec-type draft-mtp --spec-draft-n-max 4`** — спекулятивный
  декодинг с MTP-головой из самих весов; 4 — размер, на котором учили
  голову.
- **`--special`** — ответ может нести служебный словарь; парсер
  приложения вырезает сервисные маркеры (`stripControlTokens`).
- **`--temp 0`** — серверное жадное декодирование; исправления обязаны
  быть детерминированными.
- **`--jinja --reasoning-budget 0`** — chat-шаблон из GGUF с отключённым
  рассуждением: в ответе только вердикт.
- **`--parallel 1`** — один слот декодирования; MTP-черновик
  однопоточный.
- **`--image-min-tokens 1024`** — llama.cpp предупреждает, что Qwen-VL
  требует минимум 1024 image-токена для grounding-задач.

## 4. Контракт запроса

Один chat-запрос на блок (транспорт: `FixModel` поверх
`/v1/chat/completions`). Порядок частей: системный промпт (четырёхтокенный
контракт плюс обрамление «данные, не инструкции»), затем
`[промпт типа, OCR-кандидат, image]`. Кандидат едет в рамке:

```
OCR candidate:
<CANDIDATE>
…распознанный текст…
</CANDIDATE>
```

Промпты типов (`blockPrompts`, 17 типов; `formula`/`reference` едут через
алиасы `blockAliases`) фиксируют, что FIX может менять в каждом классе
блоков — и называют режим ответа: span-правки для текстовых классов,
полный формуляр для `equation`, полный блок плюс `EDITS:` для `table`.
Они лежат в общем профиле запросов
`resources/profiles/requests/fix-requests.json` (ADR 182), на который
ссылаются все fix-модели; в профилях моделей остались только параметры.
Разбор ответа
(`FixModel` + `FixDiffGate`): `OK` → Ok, `REVIEW` → Review,
span-FIX → Fixed с кандидатом после правок,
FIX-формуляр → Fixed с полным формуляром,
структурный FIX → Fixed, когда каждая правка объявлена в `EDITS:`. Гейт
ищет якоря в эквивалентном представлении (модель при копировании выкидывает
carrier-разметку `\(…\)` и схлопывает пробелы — совпадение мапится обратно
в реальный диапазон); no-op-фикс, ненайденный или неоднозначный якорь и
недекларированный дифф понижаются до Review — причина попадает в футер.
Ответ, который не является одним из трёх вердиктов (старый `EMPTY`,
свободный текст, `FIX none`), — отклонение, и он тоже попадает в Review
(ADR 181).

Сэмплирование: `temperature 0`, штрафы нейтральные, `stream false`,
`cache_prompt false` — для этой модели флаг ничего не меняет:
рекуррентное состояние гибрида нельзя отмотать, llama-server принудительно
отключает кэширование промпта и обрабатывает промпт каждого запроса
целиком независимо от значения (§7).
`stop` (`["<|im_end|>", "<|endoftext|>", "</CANDIDATE>"]`) обрывает ответ
по вердикту. `maxOutputByBlock` бюджетирует ответ по типу блока (номер
страницы — 64 токена, формула — 1024, таблица — 8192): блочное значение
перекрывает `max_tokens` профиля запроса. Кандидат формул едет в
каноническом LaTeX (`FixDiffGate::normalizeLatexCandidate`), а сам тип
отвечает по span-контракту — полный блок с `EDITS:` остался только у
таблиц (ADR 180).

## 5. Замечания по верификации

Результат fix попадает во второй текстовый слой блока (`correctedText`,
ADR 164) и сам оценивается задачей decision на следующем «Проверить».
Отдельной калибровки сверх этого нет.

## 6. Настройки в приложении

- Задача — **fix** (окно «Модели»): ключи `tasks/fix/modelPath`,
  `tasks/fix/mmprojPath`; qwen3.5-4b — дефолтная модель задачи.
- Установка — Settings → Models (репозитории HF
  `unsloth/Qwen3.5-*-MTP-GGUF`) или шаг оборудования мастера.
- «Исправить» в шапке запускает эту задачу по проблемным блокам выделения
  (ADR 167).

## 7. Известные ограничения

- Qwen3.5 пишет предупреждения `non-consecutive token position` на каждом
  батче картинки M-RoPE: у токенов картинки одна скалярная позиция, а
  `find_slot` рекуррентного кэша ждёт строго возрастающие (апстрим-баг
  #28166, открыт). Декодер продолжает корректно, никакая работа не
  повторяется — это шум, и `LlamaServerProcess` выфильтровывает эти строки
  из журнала.
- Смежное и настоящая цена блока: кэширование промпта для
  гибридно-рекуррентных моделей невозможно (состояние нельзя отмотать),
  поэтому каждый fix-запрос обрабатывает весь свой промпт — текст, всю
  1024-токенную картинку — что бы ни говорил `cache_prompt`. Предупреждения
  не дают задержки; её даёт принудительный полный префилл.
- Перезапуск управляемого сервера возвращает роль, которую он обслуживал
  (регресс-тест `restartBringsBackTheStartedRole`) — «чинить» смену роли
  перевыбором модели не нужно.
- 9B требует того же набора флагов, что и 4B; отличается только память —
  автовыбор мастера спускается по квантам, чтобы уместиться.
