## Предварительная обработка изображения:

### 1. Простая

1. Обрезать поля (Порог «белого» настраиваемый (по умолчанию яркость > ~240)), учитывать обрезку при отрисовке блоков в дальнейшем.
2. Сжать изображение перед отправкой. Только уменьшение, по большей стороне до 1024, `Qt::SmoothTransformation`

### 2. Комплексная (OpenCV)

1. Автоматическая расстановка блоков - заголовки, текст, рисунки, таблицы, формулы, подписи. +ручная корректировка
   1. Нарезка на абзацы: **Алгоритм строк:** бинаризация → горизонтальная проекция  (сумма тёмных пикселей по строкам) → находим «пустые» полосы между  строками → предпочитаемые точки реза; крупные промежутки трактуем как  границы абзацев.
   2. Резка: набираем строки в блок, пока высота ≤ ширины; режем в самом широком доступном межстрочном промежутке ближе к лимиту.

2. Отправка в llm только текстовой части.
