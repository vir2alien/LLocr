- Зависание интерфейса при загрузке и работе fix-модели

- Мастер настройки - затык на последнем шаге (скачивание и проверка). Сначала появляется ошибка, потом ничего не происходит.

- Интерфейс
  - Общие настройки распознавания
    - не включать служебные блоки по выбору

- OCR-Jev
  - сделать калибровку порога на всех блоках

- Авто-режим:
  - остаётся один режим (без выбора уровня сложности) - одна кнопка "распознать"
  - пайплайн авто-режима: разметка - распознавание блоков - проверка блоков (указанных в настройках) - исправление проблемных блоков - проверка исправленных блоков. Пайплайн должен быть модульным и легко изменяемым. Напимер, должна быть простая возможность добавить распознаваине разных блоков разными моделями.

- Перед релизом выставить оптимальные значения по умолчанию, удалить из настроек код, отвечающий за миграцию между версиями.
