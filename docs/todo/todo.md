- Исправления
  - Мастер настройки - затык на последнем шаге (скачивание и проверка). Сначала появляется ошибка, потом ничего не происходит.
  - Отменить исправление на блоке не отменяет его в превью

- Интерфейс
  - В настройках вывода выставить блоки, которые можно не добавлять в результат
  - Панель блока
    - Убрать из названия блока "block"
    - Добавить score проверки и результат исправления (Не требует исправления, исправлено, повреждено)
    - Не показывать исправленный текст, если блок ОК
    - Переключение между исправленным и исходным блоком
  - одели, выбор квантов и моделей - подписать требования по видеопамяти для конкретных ситуаций.
  - Режим редактирования блока, чтобы нельзя было его случайно двигать
  - При добавлении блока не пихать его сразу на превью. Режим добавления блока для мышки (кли определяет один из углов, дальше растянуть)

- Работа с формулами
  - очищать результаты распознавания формул после рапознавания, а не перед передачей в модели
  - браковать блок формулы сразу, если можно выявить проблемы на уровне latex, исключать его из проверки

- Определять ориентацию страницы. Автоповорот. Ручной поворот. При повороте страницы с неё всё удаляется, страница сбрасывается в состояние до распознавания.

- Задачи для decision-моделей
  - Выбор пайплайна (быстро, баланс, точно) под каждую отдельную страницу
  - Вращение изображения, если нельзя точно реализовать алгоритмически

- Авто-режимы:
  - Быстро - распознавание одной моделью
  - Баланс - распознавание в два этапа (разметка, распознавание блоков), проверка, исправление
  - Точно - разметка, распознавание блоков (оптимальными моделями под каждый блок), проверка, исправление, проверка
- Нужен профиль, где будут перечислены оптимальные модели под разные задачи. Удалить из профилей моделей default, чтобы не перегружать их информацией.

- Внешний рантайм:
  - В интерфейсе алиасы под каждую задачу
  - oMlx - протестировать все модели

- Перед релизом выставить оптимальные значения по умолчанию, удалить из настроек код, отвечающий за миграцию между версиями.
