# OCRtest / manual — ручные стенды READ и FIX

Два скрипта для одиночных CLI-запросов к llama-server с ручными конфигами.
Всё редактируется в текстовых конфигах — по одному параметру на строку.

## Файлы

| Файл | Что это |
| --- | --- |
| `stand.py` | Общий движок: разбор конфига, запуск/переиспользование llama-server, запрос |
| `read.py` | Стенд READ: кроп → расшифровка |
| `fix.py` | Стенд FIX: кроп + кандидат → OK / FIX / REVIEW |
| `read.txt` | Конфиг READ |
| `fix.txt` | Конфиг FIX |

## Запуск

```bat
py OCRtest\manual\read.py
py OCRtest\manual\fix.py
py OCRtest\manual\read.py другой-конфиг.txt --restart
```

Скрипт сам поднимает llama-server из конфига (лог — `server.log`) и ждёт
`/health`. Уже работающий сервер с теми же параметрами запуска
переиспользуется; при изменении блока «Сервер»/«launch» пересапается при
следующем запуске; `--restart` пересапает принудительно. Порт занят чужим
процессом — скрипт завершится с сообщением, сам чужой процесс не трогает.

READ и FIX используют один порт и одинаковый блок запуска, поэтому делят
один сервер: правки запросов идут без пересапа.

## Формат конфига

Каждый параметр с новой строки: `ключ = значение`. Значение продолжается на
следующих строках **с отступом** (склеиваются переводом строки — так пишутся
многострочные system/prompt). Строки с `#` и пустые пропускаются. Ключи
регистронезависимые, с начала строки. Относительные пути — от папки конфига.

Ключи:

| Ключ | Смысл |
| --- | --- |
| `runtime` / `model` / `mmproj` | Путь до llama-server.exe и GGUF-файлов |
| `host` / `port` | Адрес сервера |
| `wait` / `timeout` | Ожидание загрузки модели и таймаут запроса, с |
| `max_tokens` | Лимит ответа |
| `launch` | Флаги llama-server — по одному на строку |
| `system` / `prompt` | Системный запрос и типовой запрос блока |
| `candidate` | Только FIX: кандидат (текст распознавания) |
| `image` | Путь до кропа |
| `params` | Поля тела запроса: `имя = json-значение` по строке |

Результат печатается в консоль и сохраняется в `last_read.txt` /
`last_fix.txt` (UTF-8; консоль может показывать кириллицу искажённо — файл
верный).
