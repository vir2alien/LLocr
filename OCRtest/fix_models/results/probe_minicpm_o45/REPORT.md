# Проба: «распознать с нуля» против «исправить ранее распознанное» — MiniCPM-o 4.5

Модель: **minicpm-o-4.5** (MiniCPM-o 4.5, Q4_K_M; внутри — Qwen3-8B, SigLIP2-проектор
64 токена на срез). Рантайм: llama.cpp b11799 на **CPU** (`--device none --n-gpu-layers 0`).
Запуск по профилю: `--temp 0 --no-warmup --jinja --reasoning-budget 0 --flash-attn on
--special`, без `--spec-type` (драфтера нет) и без `--image-min-tokens` (сlicing модели).

Корпус, обе руки, промпты и метрики — те же, что в `results/probe_gemma4e4b/REPORT.md`.

## Результат

```
uid       CER кандидата  CER fix  CER read  инд канд  инд fix  инд read  вердикт fix
p03b03            0.256    0.256     0.052      0.33     0.33      0.89       Review
p03b05            0.097    0.097     0.014      0.45     0.45      0.91       Review
p03b12            0.161    0.161     0.143      0.43     0.43      1.00       Review
p03b14            0.213    0.213     0.081      0.38     0.38      0.75       Review
p05b09            0.041    0.041     0.057      1.00     1.00      1.00       Review
СРЕДНЕЕ           0.154    0.154     0.069      0.52     0.52      0.91
```

**Рука fix не сделала ровно ничего: 5 × Review, ноль изменений.** Модель отвечает на
каждый запрос двумя токенами — `FIX` — и закрывает Turn. Гейт: «вердикт есть, полезной
нагрузки нет» → блок уходит в Review. Это в точности повторяет измерение ADR 223
(`docs/07-glossary.md`), сделанное на другом корпусе.

**Рука read — лучшее чтение из трёх моделей: CER 0.069 и 91 % прочитанных индексов.**

## Что именно прочитано

| блок    | read                                                                 | оценка |
| ------- | -------------------------------------------------------------------- | ------ |
| p03b03  | `н.впр` ×3 **верно**, `п` → `n` (латинская n), `p` → `ρ`              | CER 0.052 |
| p03b05  | `Q_{терм}`, `R_{в}`, `T_{н.впр}`, `Q_{исп.впр}`, `M_{н.впр}` — **верно**; `M_т` → `M_T` | CER 0.014 |
| p03b12  | `н.впр` ×3 **верно** (индексы 1.00), потерян тег `(2.69б)` и `\bar{\tau}` | CER 0.143 |
| p03b14  | `н.впр` ×2 **верно**, `M_v` → `M_в` (кириллическая в), тег `(2.70a)` латиницей | CER 0.081 |
| p05b09  | структура и все 13 индексов на месте; `v_r` → `V_r`, знак у `v_θ²` перепутан, `\eta r` → `\eta_r`, тег `(63a)` латиницей | CER 0.057 |

Прочитанное `н.впр` — ровно то, что не прочитала ни одна fix-рука ни на одной из трёх
моделей (`H.Bnp`, `H.BPp`, `H.BIpp`).

## Сводка по трём моделям

```
модель              кандидат      fix     read      инд: канд / fix / read   вердикты fix
gemma-4-e4b  (4B)     0.154     0.153    0.069            0.52 / 0.54 / 0.87   5 × Fixed
qwen3.5-4b   (4B)     0.154     0.142    0.187            0.52 / 0.58 / 0.57   1 × Ok, 4 × Fixed
minicpm-o-4.5 (8B)    0.154     0.154    0.069            0.52 / 0.52 / 0.91   5 × Review
```

| модель              | читает с нуля | чинит кандидата | среднее время (CPU) |
| ------------------- | ------------- | --------------- | ------------------- |
| gemma-4-e4b  (4B)   | **0.069**     | 0.153 (нет)     | 106 / 118 с         |
| qwen3.5-4b   (4B)   | 0.187         | 0.142 (нет)     | 48 / 47 с           |
| minicpm-o-4.5 (8B)  | **0.069**     | 0.154 (нет)     | 45 / 48 с           |

Ключевое из трёх замеров:

1. **Ни одна fix-рука ни на одной модели не дала улучшения, которое можно назвать
   исправлением.** Средний CER после fix: 0.153, 0.142, 0.154 против 0.154 кандидата.
   Разница в пределах шума. Когда рука всё же что-то меняла, она воспроизводила
   кандидата (gemma, qwen) — с теми же ошибками скрипта.
2. **Руки read и fix сравнимы по объёму работы, но не по качеству.** read строит блок
   с нуля и ошибается в мелких индексах реже, чем fix, который имеет кандидат под рукой.
3. **Модель, объявленная негодной как чинильщик (MiniCPM, ADR 223), оказалась лучшим
   читателем из трёх.** Её 0.069 и 0.91 против 0.153/0.54 у gemma.

## Чего не чинит ни одна рука

Кириллические буквы в тегах (`2.69б`, `2.70а`, `63а`). MiniCPM написал `(2.70a)` и
`(63a)`, qwen — `(2.70a)`, gemma — `(2.70a)`. Глифы «б» и «а» неотличимы от «6» и «a»
без знания конвенции документа; это знание, а не чтение.
