# Проба: «распознать с нуля» против «исправить ранее распознанное» — qwen3.5-9b

Модель: **qwen3.5-9b** (Qwen3.5-9B, MTP, UD-Q4_K_XL, 6.1 ГБ + проектор 0.9 ГБ).
MTP-драфтер внутри самого GGUF (`--spec-type draft-mtp`, отдельный файл не нужен).
Рантайм: llama.cpp b11799 на **CPU** (`--device none --n-gpu-layers 0`), ctx 16384.

Корпус, обе руки, промпты и метрики — те же, что в `results/probe_gemma4e4b/REPORT.md`.

## Результат

```
uid       CER кандидата  CER fix  CER read  инд канд  инд fix  инд read  вердикт fix
p03b03            0.256    0.113     0.274      0.33     0.44      0.22        Fixed
p03b05            0.097    0.014     0.405      0.45     0.91      0.27        Fixed
p03b12            0.161    0.161     0.242      0.43     0.57      0.43        Fixed
p03b14            0.213    0.066     0.250      0.38     0.38      0.38        Fixed
p05b09            0.041    0.033     0.033      1.00     1.00      1.00        Fixed
СРЕДНЕЕ           0.154    0.077     0.241      0.52     0.66      0.46
```

**Теория переворачивается.** Рука fix (0.077) втрое ближе к эталону, чем рука read
(0.241), и вдвое ближе, чем сам кандидат (0.154). Это лучший результат fix-руки среди
всех пяти моделей — при том, что у 4B-версии той же семьи было 0.142.

## Что именно сделала fix-рука

| блок    | кандидат | fix | что изменилось |
| ------- | -------- | --- | -------------- |
| p03b03  | `H.Bnp`  | `H.впр` | индекс переведён в кириллицу (кроме первой буквы) |
| p03b05  | `M_T R_B T_{Нвпр}` | `M_{т} R_{в} T_{нвпр}` | **все индексы кириллические и верные**; `Q_{терм}`, `Q_{исп.впр}`, `M_{нвпр}` |
| p03b12  | `H.BPp`  | `H.ВПР` | транслитерация в кириллицу, но **капителью — неверно** |
| p03b14  | `H.Bnp`  | `H.впр` | индекс переведён в кириллицу |
| p05b09  | `v_r` → `V_r` | без изменений | мелочь |

CER 0.014 и доля индексов 0.91 на p03b05 — это фактически полное исправление блока.

## Что сделала read-рука — и почему хуже

| блок    | read | оценка |
| ------- | ---- | ------ |
| p03b03  | `H.BIIp` | транслитерация хуже, чем у 4B (`H.BIpp`) |
| p03b05  | `Q_{\mathrm{TePM}}`, `Q_{\mathrm{HCII.BIIp}}` | **кириллица превратилась в латиницу целиком** |
| p03b12  | `H.BIIp` | то же |
| p03b14  | `H.BIIp` | то же |
| p05b09  | структура и 13 индексов на месте | CER 0.033 |

Здесь и кроется главный результат: **с кандидатом в руках qwen-9b кириллицу читает
почти безупречно (0.91 индекса на p03b05), а без кандидата — переводит её в латиницу
(`TePM`, `HCII.BIIp`) хуже, чем это делает 4B-версия той же модели.**

Кандидат для qwen-9b — не помеха и не поводок. Это **якорь**: он держит структуру и
скрипт, и модель тогда дотягивает до мелочей. Без него модель строит формулу заново и
теряет скрипт в первую очередь.

## Сводка по всем моделям

```
модель              кандидат      fix     read      инд: канд / fix / read   вердикты fix
gemma-4-e4b  (4B)     0.154     0.153    0.069            0.52 / 0.54 / 0.87   5 × Fixed
qwen3.5-4b   (4B)     0.154     0.142    0.187            0.52 / 0.58 / 0.57   1 × Ok, 4 × Fixed
minicpm-o-4.5 (8B)    0.154     0.154    0.069            0.52 / 0.52 / 0.91   5 × Review
qwen3.5-9b   (9B)     0.154     0.077    0.241            0.52 / 0.66 / 0.46   5 × Fixed
gemma-4-12b  (12B)    —          —        —                      —               —
```

**Разница между 4B и 9B внутри одного семейства — качественная, а не количественная.**

| модель              | читает с нуля | чинит кандидата | кто лучше |
| ------------------- | ------------- | --------------- | --------- |
| gemma-4-e4b  (4B)   | 0.069         | 0.153           | read      |
| qwen3.5-4b   (4B)   | 0.187         | 0.142           | fix (чуть) |
| minicpm-o-4.5 (8B)  | 0.069         | 0.154           | read      |
| qwen3.5-9b   (9B)   | 0.241         | **0.077**       | **fix**   |

Теория «маленькие модели распознают с нуля лучше, чем исправляют» верна там, где
модель слаба как чинильщик (gemma-4-e4b — не чинит ничего; MiniCPM — не приносит блок
вовсе; qwen3.5-4b — чинит вхолостую), и **переворачивается**, как только модель
дорастает до настоящего чинильщика (qwen3.5-9b).
